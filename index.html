Règles

🎯 Objectif

Le téléphone choisit secrètement un nombre de 3 chiffres différents. Ton objectif est de le retrouver avant la fin du chrono.

🟢 V — Chiffre bien placé

Un V signifie qu'un chiffre est correct et placé exactement au bon endroit.

🟡 X — Chiffre mal placé

Un X signifie qu'un chiffre appartient au code mais n'est pas à la bonne position.

Exemple

Code secret : 527

Proposition : 572

Résultat : 1V 2X

⚠️ Important

  • Les trois chiffres du code sont différents.
  • Un même chiffre n'est compté qu'une seule fois.
  • Le chrono continue pendant toute la partie.
  • Le score dépend notamment du niveau, du temps et des essais.
